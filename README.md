# Deepskilling Java FSE

This repository contains the projects and exercises for the Deepskilling Java Full Stack Engineering (FSE) program.

## Repository Contents

- **Week 1**: Core Java, Data Structures, Algorithms, Design Patterns, and Maven.
- **Week 2**: Spring Core, Spring Boot, Spring MVC, Spring Data JPA, and Hibernate.
- **Week 3 / Spring Learn**: Spring MVC / Spring REST API, Spring Boot Security, and JWT.
- **Week 4**: Microservices architecture, Spring Cloud, Spring Config Server, Eureka Server, Gateway, Feign Clients.
- **Week 5**: ReactJS frontend applications and UI/UX styling.
- **Week 6**: Git version control, branch management, merge conflict resolution, and remote repository synchronization.
